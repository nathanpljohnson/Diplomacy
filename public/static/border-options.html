ENTENTE · FIVE BORDER STUDIES

Same provinces. Five ways to draw the edges.

These are visual options, not changes to the live game. Each uses one shared border between neighboring provinces, so the pale gaps and overlapping dark edges are removed.

Example position

Example: Belgium (BEL) and Holland (HOL) are French. Compare whether the outline moves with the colors.

What stays the same?

The province arrangement, names, country colors, unit symbols, supply-center markers, and example position are the same in every option. This preview closes artwork gaps to create shared edges; it does not change the live adjudicator or its legal movement graph.

Reading the alternatives: options 1, 2, and 5 follow territorial control. Option 3 uses colors alone to show control. Option 4 deliberately keeps the original national outlines while ownership colors expand.
